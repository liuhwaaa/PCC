แผนงาน Digital Content + เอกสาร

เว็บแอปจัดการงานสไตล์ Notion แบบ Kanban board สำหรับรวมงาน Digital Content และ งานเอกสาร ไว้ในที่เดียว ใช้งานง่าย ไม่ต้องติดตั้งอะไร เปิดผ่านเบราว์เซอร์ได้ทันที

🔗 ลิงก์ใช้งาน: https://liuhwaaa.github.io/PCC/

ฟีเจอร์
📋 Kanban board ลากการ์ดสลับสถานะได้ทันที — Backlog → กำลังทำ → รอตรวจ → แก้ไข → เสร็จแล้ว
🎬📄 แยกมุมมองงานตามประเภท: Digital Content / งานเอกสาร

⚠️ แจ้งเตือนงานที่เกินกำหนดส่งอัตโนมัติ
